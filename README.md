# Chromosome Designs Website

Next.js + Tailwind implementation of the Chromosome Designs portfolio website.

## Run locally

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Structure

- `app/` - Next.js App Router pages
- `components/` - Shared React components
- `lib/projects.js` - Project data used by portfolio and case-study pages
- `public/assets/images/` - Local SVG visual assets
- `app/globals.css` - Tailwind entry and global component styles
